# Handler geliştirme

> [English](../HANDLER-GUIDE.md) | **Türkçe**

Güncel talimatlar [geliştirici rehberindedir](TECHNICAL-GUIDE.md). Rehber 1.1.0 için handler arayüzünü, tam ek okuma örneğini, işlem sözleşmesini, yeniden denemeyi, mükerrerliği ve kabul kontrollerini kapsar.

ABAP yazmadan ayarlar ve günlük kullanım için [adım adım rehberle](WALKTHROUGH.md) başlayın.
