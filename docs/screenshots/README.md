# Screenshot scope / Ekran görüntülerinin kapsamı

Captured on A4H, SAP GUI 8.00, 2 November 2026. These are real standard SAP screens, with English SAP menu labels and explanations in the English/Turkish walkthroughs.

| File | What it shows | What it does not establish |
|---|---|---|
| sap-se38-installer-entry.png | SE38 before Create, with ZCHE_IMAP_INSTALL entered. | Program installation or activation. |
| sap-program-attributes.png | Initial unfilled program attributes dialog; Type still needs selection. | Saved program properties or installed objects. |
| sap-sm36-job-definition.png | Unsaved SM36 draft with an example job name. Target, step and timing remain unfilled. | Scheduled, released, executed or successful job. |

The current ZCHE_IMAP_CONFIG program was not installed in the available SAP session. Current installer selection, profile, INBOUND, monitor/result and completed job screenshots are therefore not included. Old ZIMAP screenshots have not been relabeled as the current release.

No installer was saved/executed, no mail fetched/processed and no background job saved or released for these images. Creating the empty attributes dialog was canceled without saving. Main-window captures are cropped to the relevant controls, excluding unused space and the pointer; the dialog capture is native. Labels and values have not been redrawn or translated.
